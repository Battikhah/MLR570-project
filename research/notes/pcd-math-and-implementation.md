# PCD / FedPCD mathematics and implementation audit

Checked 2026-11-02. Claim labels below apply sentence-by-sentence; **VERIFIED** means checked against a primary paper, author page, repository page, or dataset owner, and **INTERPRETATION** marks analysis. Evidence types are called out separately.

## Primary sources and status

AlHajri, [“Not All Objectives Are Born Equal: Priority-Constrained Descent for Hierarchical Multi-Objective Optimization”](https://arxiv.org/abs/2606.29521), arXiv v2 dated 2026-09-21; the author project page states TMLR 2026 and links OpenReview [HT01yGHLEt](https://openreview.net/forum?id=HT01yGHLEt). ## PCD formulation, derivation, edge cases

Let `L1` be the priority objective, `L2 … LK` secondary objectives, `gi` their gradients/subgradients at the current parameters, and `g̃i = si gi` their normalized gradients. **VERIFIED:** The paper solves

```text
d̃* = argmin_d̃  1/2 ||d̃ - g̃1||²
     subject to  g̃jᵀ d̃ ≥ τ ||g̃j||²,  j = 2,…,K.
```

It is a Euclidean projection of the primary gradient onto the intersection of secondary progress half-spaces. The KKT stationarity equation is `d̃* = g̃1 + Σj μj g̃j`, `μj ≥ 0`; complementary slackness sets `μj=0` for constraints with slack. This sign is consistent with descent updates `θ ← θ − η d`: `gjᵀd > 0` is first-order decrease in `Lj`.

**INTERPRETATION — independent derivation for K=2:** Let `a=g̃1`, `b=g̃2≠0`. If `bᵀa ≥ τ||b||²`, `a` is already feasible and is the minimizer. Otherwise the closest point in the half-space is the orthogonal projection correction `a + ((τ||b||²−bᵀa)/||b||²)b`, equivalently `a +(τ−bᵀa/||b||²)b`; substituting verifies equality at the boundary. This is unique because the objective is strictly convex. If `b=0`, its constraint is `0≥0` and the answer is `a` (the ratio form must not be evaluated).

**VERIFIED:** For K≥3, the same QP is solved through KKT active-set enumeration in the experiments (at most `2^(K−1)` working sets), with a dual active-set option discussed for larger K. If active set A is fixed, multipliers solve the Gram system `G_A μ_A = τ diag(G_A) − G_A,1` (equivalently each active RHS is `τ||g̃j||²−g̃jᵀg̃1`); retain only nonnegative multipliers and check all primal constraints. K=3 admits a two-by-two closed form/Cramer’s rule. The optimizer/backpropagations dominate this small Gram solve.

**VERIFIED — hierarchy scope:** The paper generalizes from two objectives to one primary plus any number of peer secondaries, all with the same scalar τ; it also notes separate `τj` values as a `(K−1)`-dimensional operating manifold. A fully ordered multi-level hierarchy with distinct cascading priorities is described as future work, not as a proven or evaluated algorithm in this paper. For a single active subset A, `μA=G_A⁻¹b_A`, where `b_j=τ||g̃j||²−g̃jᵀg̃1`; that formula is valid only when the active gradients are linearly independent and the resulting multipliers are nonnegative and all inactive constraints remain feasible. Degenerate active sets require checking alternate subsets or a robust QP solver.

**VERIFIED — normalization and rescaling:** For each objective, the paper uses scalar EMA of squared raw gradient norm: `vt=βvt−1+(1−β)||gt||²`, bias correction `v̂t=vt/(1−βᵗ)`, `st=1/sqrt(v̂t+ε)`, then `g̃t=st gt`. At steady state each nonzero normalized gradient has norm roughly 1. Multiplying a loss by positive `c` correspondingly scales its raw gradient and EMA, so normalized directions are invariant asymptotically / as `ε→0`; finite `ε` leaves residual dependence. After the QP, the paper rescales `d̃*` to the primary raw-gradient norm: `d* = d̃* ||g1|| / ||d̃*||`; update direction norm is thus set by primary magnitude. This is a norm rescale, not a guarantee that the update remains a descent direction for the primary.

**INTERPRETATION — assumptions:** QP convexity/uniqueness needs only a nonempty feasible set because the Hessian is identity; it does not require objective convexity. The paper’s stated objective regularity assumes a continuously differentiable primary and proper, convex, lower-semicontinuous secondaries with accessible subgradients. First-order secondary decrease is exact for smooth secondaries (with a local step-size/smoothness allowance); nonsmooth convex secondaries require the paper’s “kink tax” correction where a step enters zeroed coordinates/groups/singular directions. Neural-network task losses and KD losses are nonconvex, so convex-secondary convergence statements do not directly cover the proposed CE/KL pair; the numerical QP still exists when its sampled gradients are supplied, subject to feasibility.

### Feasibility, degeneracy, and τ

- **VERIFIED:** For one secondary and nonzero `g̃2`, the half-space is nonempty for any real RHS, hence all `τ∈[0,1]` are feasible; `τ` is the method’s prescribed range, not a feasibility theorem’s limit. If the secondary gradient is zero, its constraint is vacuous. If the primary gradient is zero, the QP still has a feasible nonzero solution for K=2 and `τ>0`, but the deployed PCD algorithm explicitly takes a zero step at a primary-stationary point; the theoretical direction and implemented step therefore differ at this boundary.
- **VERIFIED:** For multiple nonzero secondaries and `τ>0`, Farkas’ lemma says infeasibility occurs exactly when a nonzero nonnegative combination of secondary gradients is zero (equivalently, zero lies in their convex hull after normalizing combination weights). Exact anti-parallel secondary gradients are a simple infeasible example; near anti-parallel constraints can be feasible but ill-conditioned / demand large corrections. At `τ=0`, `d̃=0` is always feasible, so this particular infeasibility cannot occur. A practical solver must have an explicit infeasibility policy; PCD paper drops all secondary constraints for the step and takes primary direction. A zero secondary contributes no constraint. Linearly dependent active gradients make Gram systems singular, so a valid implementation must reject/de-duplicate that working set or use a robust QP solver; primal solution remains unique even when multipliers are not.
- **VERIFIED:** In the two-objective unit-norm active case with cosine `c=g̃1ᵀg̃2`, `g̃1ᵀd̃*=1+τc−c²`. Primary first-order descent is preserved iff this is positive. With conflict `c<0`, the necessary strict condition is `τ < (1−c²)/(−c)`; at/beyond the threshold the secondary constraint can erase or reverse first-order primary progress. Thus “primary objective is preserved” should be read as the projection is anchored to it, not as unconditional primary descent.
- **INTERPRETATION:** At `τ=0`, constraints require only nonnegative first-order secondary progress; at larger τ, the feasible intersection shrinks and its closest point may distort the primary direction more. `τ=1` means full normalized own-gradient progress per constraint, not guaranteed coexistence of all constraints. Positive τ plus feasible QP makes secondary direction progress explicit, but actual finite optimizer steps, stochastic mini-batches, momentum/Adam preconditioning, and nonsmooth kinks can change realized loss behavior.

### Relation to other approaches

- **VERIFIED / INTERPRETATION:** Weighted sum optimizes `Σ wiLi`; weights trade tasks but do not encode hierarchy structurally, and change under objective rescaling unless weights are retuned. PCD fixes the primary coefficient at one in its KKT correction representation and uses normalized-gradient constraints. This distinction matters only if the application truly has an externally justified primary objective.
- **VERIFIED / INTERPRETATION:** MGDA seeks a minimum-norm convex combination of objective gradients and targets Pareto stationarity; it treats objectives symmetrically and can return zero when gradients cancel, even though individual losses remain nonstationary. PCD’s normalized direction has a composite-multi-stationarity characterization when `τ>0` and feasible. This is a fixed-point characterization, not proof its deployed trajectory reaches such a point.
- **VERIFIED / INTERPRETATION:** PCGrad projects away pairwise negative conflict (depending on projection order) but the PCD paper notes no per-objective progress guarantee. CAGrad balances average descent with conflict aversion; it also does not encode primary/secondary semantics. PCD is asymmetric. It should be compared with appropriately tuned versions rather than dismissed; in PCD’s own compression study tuned application-specific group-lasso scalarization comes within reported seed noise at one headline compression point.
- **VERIFIED:** PCD’s two-objective QP is a specialization of dynamic-barrier / constrained-optimization direction constructions. The paper itself cautions the equivalence is direction-only because it uses normalization and magnitude rescaling. Lexicographic optimization would first optimize a primary to a defined tolerance/set, then optimize secondary objectives without violating that primary criterion. PCD is not strict lexicographic optimization: its single local projection asks for secondary progress and may sacrifice primary first-order descent under strong conflict. A constrained method that minimizes primary loss subject to an explicit secondary/accuracy/fairness bound may better fit hard policy limits and should be included when applicable.

## Convergence guarantees and neural-network limits

- **THEORETICAL GUARANTEE — PCD:** The primary PCD paper’s principal results are properties of the QP solution: feasibility-conditioned first-order secondary directional progress; scale invariance in the EMA limit; and (for `τ>0`, feasible QP) `d̃*=0` iff all objectives are individually stationary in its stated gradient/subgradient sense. These characterize computed directions at an iterate. The paper explicitly does not prove global convergence for the deployed normalized/rescaled optimizer; its sufficient-decrease sketch needs smoothness/boundedness, feasible QPs, a uniform positive alignment of the normalized primary gradient with the QP direction, and a small enough step size. That alignment can fail in severe conflict. No general deep-network convergence result follows.
- **INTERPRETATION:** The paper uses convexity of secondaries to reason about subgradients, but cross-entropy/KL over neural parameters is not convex in general. Even for smooth nonconvex losses, a sampled gradient is a noisy estimate; EMA normalization, finite τ, SGD, and momentum affect actual updates. The MLR570 reliability-gated KD method should be treated as a hypothesis, not as covered by PCD’s theorem.
- **THEORETICAL GUARANTEE — FedPCD:** FedPCD’s O(1/T) round-average squared global-gradient bound assumes full participation, deterministic local gradient descent with fixed K local steps, no client history (`H=0`), fixed positive client weights, each client objective L-smooth, global objective bounded below, positive constant rates meeting the stated upper bound, QP feasibility, and a uniform positive alignment margin γ between the constrained update and every nonzero client pseudo-gradient. It assumes no convexity and no bounded local gradients. Its client stationarity conclusion is also conditional on this geometry.
- **INTERPRETATION:** FedPCD’s theorem does not cover stochastic mini-batches, partial participation, cached stale directions (`H>0`), or arbitrary heterogeneous clients. Those are used in reported experiments, which are empirical rather than covered by that theorem. The per-round first-order alignment is not a guarantee that every local loss or client test accuracy decreases, nor is it a privacy guarantee. The server receives individual client updates and caches them, so standard secure aggregation hiding per-client updates conflicts with this implementation design.

## FedPCD formulation and cost

**VERIFIED:** Each participating client performs K local steps and sends displacement `Δi,t=θt−θi,t(K)`. The server converts it to pseudo-gradient `gi,t=Δi,t/ηℓ`, computes the current-participant FedAvg-weighted average `ḡt=Σi∈St p̄i,t gi,t`, normalizes aggregate and client vectors (with ε), then solves `min 1/2||d̃−g̃0||²` subject to `g̃iᵀd̃ ≥ τ||g̃i||²`. KKT gives aggregate direction plus nonnegative active-client corrections. It rescales the solution to `||ḡt||` and applies the server step. With partial participation, cached client pseudo-gradients from the last H rounds add constraints only; they do not enter the current primary average. Thus every client must disclose its individual update to the server; communications still include ordinary model broadcast/update upload, with extra server-side storage and a larger projection QP as represented-client count grows.

**INTERPRETATION:** Unlike standalone PCD’s objective-wise EMA normalization, FedPCD normalizes each pseudo-gradient vector to near unit norm. This removes magnitude from progress constraints, but direction quality can drift after multiple local steps. Feasibility issues generalize: for τ>0 no positive common progress is possible if nonzero cached/current client directions have zero in their convex hull. Stale history can add constraints that no longer describe the current client gradient and can make QP infeasible; must log feasible rate/fallback frequency and compare H=0 vs H>0.
